# The painted forest

A third-person WebGL experience built with Next.js, React Three Fiber, Rapier,
and Ecctrl. Explore a forest clearing and jump through paintings to enter a
gallery or a movement-testing level.

## Run locally

Requires Node.js 20.9 or newer.

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Controls

- `WASD` or arrow keys move and turn the character.
- Drag across the world to orbit the camera.
- Hold `Shift` to run.
- Press `Space` to jump.
- Jump into a painting to travel between levels.

Touch controls appear on small or touch-enabled screens.
